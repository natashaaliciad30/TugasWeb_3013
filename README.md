# Natasha Alicia Daniela Portfolio

Website portfolio pribadi Natasha Alicia Daniela yang menampilkan profil singkat, pendidikan, keterampilan, hobi, pengalaman organisasi, dan informasi kontak.

## Screenshot

![Screenshot portfolio](screenshot.png)

## Penjelasan Singkat

Portfolio ini dibuat sebagai website personal yang responsif dan mudah digunakan. Halaman utama memiliki hero section, bagian tentang diri, pengalaman organisasi, serta kontak. Desain menggunakan gaya minimalis dengan animasi reveal saat pengguna melakukan scroll.

## Fitur

- Tampilan responsive untuk desktop dan mobile
- Navigasi menu mobile
- Smooth scroll antar section
- Animasi reveal saat section terlihat
- Informasi pendidikan, keterampilan, hobi, dan pengalaman

## Teknologi

- HTML5
- Plain CSS
- JavaScript DOM

## Menjalankan Project

Buka `index.html` langsung di browser atau gunakan Live Server di VS Code.

## Deployment

Project ini dapat dipublikasikan melalui GitHub Pages dengan memilih branch `main` dan folder `/root` pada pengaturan Pages repository.

## Struktur File

```text
index.html   Halaman utama portfolio
styles.css   Style dan responsive layout
script.js    Menu mobile dan animasi interaksi
```
